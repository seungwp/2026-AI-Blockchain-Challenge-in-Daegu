# 메뉴 카테고리별 날씨·행사 계수 근거표

이 문서는 "골목 한 주"의 운영 가이드 규칙이 **어떤 연구·공공자료의 어떤 수치에 근거하는지**를 한 줄씩 기록한 대장입니다.
규칙 엔진에 들어가는 모든 계수는 여기에 행이 있어야 하며, **행이 없으면 계수를 만들지 않습니다.**

## 0. 작성 원칙

1. **출처 없는 계수는 만들지 않는다.** 추정·보간·유추로 빈칸을 메우지 않는다.
2. **원문 문장·표 값을 그대로 옮긴다.** 계산해서 얻은 값(% 환산 등)은 *변환값*으로 표시한다.
3. **원 연구의 범위(지역·기간·표본)와 한계를 반드시 같이 적는다.**
4. **계수를 사용자 매출 예측으로 바꾸지 않는다.** 계수는 ① 권고의 우선순위·신뢰도 산정과 ② 근거 문구 인용에만 쓴다.
5. **단일 사례의 계수를 다른 업종·메뉴로 확장하지 않는다.**
6. 통계적으로 유의하지 않은 값(p ≥ .05)은 **채택하지 않는다.** 기록은 남기되 `REJECTED`로 표시한다.
7. **근거가 우리 가정과 어긋나면 근거를 따른다.** 어긋난 사실도 이 문서에 남긴다(→ 6절).
8. **각 출처의 한계를 화면에 함께 노출한다.** `Source.reliabilityNote` 가 리포트 출처 목록에 그대로 표시된다.
9. **링크는 검색 결과 페이지 기준이므로 인용 시 원문을 확인한다.**

## 5. 방향·정성 근거 (계수 없음)

### 5-1. 배달 소비자 군집 (sourceId 10)

데이터: KT 통신 빅데이터 '날씨별 배달 품목 차이' / **2019.7–2020.6** / 서울 **강남·강서·송파** / 가공 후 **5,000건** / K-prototype, k=3

| 군집 | 날씨·환경 | 주요 시간대 | 선호 메뉴 |
|---|---|---|---|
| 1 패턴형 식사 | 춥고 건조, 비 거의 없음, 바람 많음, 불쾌지수 낮음 | 평일 점심·저녁 | 일반 식사류 |
| 2 자유형 식사 | 포근·다소 습함, 비 거의 없음, 바람 거의 없음 | **주말 점심·저녁, 야식(21~24)** | 다양한 식사류(카페·디저트 제외) |
| 3 간식 소비 | **무덥고 매우 습함**, 간헐적 비, **불쾌지수 매우 높음** | 평일 오전부터 증가, **14~16시 급증** | **디저트·이색음식(아시안·서양)** |

**→ 활용**: 군집3이 **양식·디저트 카테고리 × 고온다습** 조건의 방향 근거(질적). 계수는 없음.

**부수 확보 — 불쾌지수(DI) 산출식** (기상청 식, 원문 p.253 인용):
```
DI = 9/5·Ta − 0.55(1−RH)(9/5·Ta − 26) + 32     (Ta: 건구온도, RH: 상대습도)
```
→ 기온·습도만으로 계산 가능. **새 조건 타입 후보(DISCOMFORT).**

**2차 인용 수치(주의)**: "겨울철 평년 기온(0~5도)을 기준으로 할 때 기온이 **영하 10~15도로 떨어지면 주문량이 평균 22.3% 증가**" — 배달의민족 자료를 머니투데이(2018)가 보도한 것을 sourceId 10이 재인용. **2차 인용이므로 `confidence: LOW`, 채택 보류.**

### 5-1-2. ★ 배달 주문 ≠ 홀 매출 — 반대 방향입니다 (sourceId 11, 12)

**이 구분이 이 문서에서 가장 실무적으로 중요한 발견입니다.**

| | 측정 대상 | 비 올 때 |
|---|---|---|
| sourceId 4 (노진원 2019) | **카드매출**(홀 포함) | 영향 없음 / 대형만 −5.0% |
| sourceId 11, 12 | **배달 주문건수** | **증가** |

→ 같은 "비"라도 **홀은 정체·감소, 배달은 증가**입니다.
→ 우리의 "비 예보 → 포장·배달 대응 점검" 권고는 **매출 감소 경고가 아니라 채널 전환 준비**라는 근거를 얻었습니다.
