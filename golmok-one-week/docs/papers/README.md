# 논문 원문 보관 폴더

계수 근거로 쓰는 논문·보고서 원문(PDF)을 여기에 둡니다.

## ⚠️ 커밋하지 않습니다

`.gitignore`에서 이 폴더의 `*.pdf`, `*.png`, `*.jpg`를 제외하고 있습니다.
저작권 자료이므로 공개 저장소에 올리지 않습니다. **이 README만 git에 올라갑니다.**

제출·심사에 필요한 것은 원문이 아니라 `../coefficients.md`의 **인용·출처·페이지 번호**입니다.

## 파일명 규칙

```
<연도>_<제1저자>_<짧은제목>.pdf
```

예:
```
2020_구교영_치킨프랜차이즈_날씨경영.pdf
2016_송사광_딥러닝_소상공인매출.pdf
2017_성은영_기상요인_식음료업매출.pdf
2015_응용통계연구_배달음식_이용건수.pdf
```

## 새 논문을 넣은 뒤

1. 위 표에 한 줄 추가
2. `../coefficients.md` 1절 출처 목록에 추가 (id 부여)
3. 계수를 뽑아 2절 또는 3절에 기록 — **원문 인용·범위·한계 필수**
4. 뽑을 계수가 없으면 그 사실도 기록 (어떤 논문이 왜 못 쓰였는지가 남아야 함)
